Using @mlightcad/dwg-converter

This example shows how to register the private DWG converter with RealDWG-Web's AcDbDatabaseConverterManager, then browse the resulting AcDbDatabase.

1. Install

pnpm add @mlightcad/data-model
pnpm add @mlightcad/dwg-converter --registry https://npm.pkg.github.com

Public @mlightcad/* packages install from npmjs. Install private @mlightcad/dwg-converter with the GitHub Packages registry flag (see .npmrc.example). Do not remap the whole @mlightcad scope to GitHub Packages.

2. Deploy parser assets

Copy from @mlightcad/dwg-converter/dist/ into a public folder (this app uses ./assets/):

  • dwg-parser-worker.js (web worker mode)
  • dwg-parser-main.js (main-thread mode)
  • dwg-codepage-*.bin (CJK fallback tables)

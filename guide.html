Using @mlight-cad/dwg-converter

This example shows how to register the private DWG converter with RealDWG-Web's AcDbDatabaseConverterManager, then browse the resulting AcDbDatabase.

1. Install

pnpm add @mlightcad/data-model
pnpm add @mlight-cad/dwg-converter

Authenticate only the @mlight-cad scope (see .npmrc.example). Do not remap the whole @mlightcad scope to GitHub Packages.

2. Deploy worker assets

Copy from @mlight-cad/dwg-converter/dist/ into a public folder (this app uses ./assets/):

  • dwg-parser-worker.js
  • dwg-codepage-*.bin (CJK fallback tables)
